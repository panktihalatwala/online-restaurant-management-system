# 🍽️ Online Restaurant Management & Order Tracking System

## 📌 Project Overview
The Online Restaurant Management & Order Tracking System is a web-based application designed to streamline restaurant operations. It enables efficient order management, menu handling, and real-time order tracking for improved customer experience and administrative control.

This project was developed as an academic team project.

---

## 🚀 Features
- 📋 Digital Menu Display
- 🛒 Online Order Placement
- 🔄 Real-Time Order Tracking
- 👨‍💼 Admin Panel for Order Management
- 📱 Responsive User Interface
- 🗂️ Organized Data Handling

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

---

## 🎯 Objectives
- To simplify restaurant order management
- To reduce manual errors
- To improve customer satisfaction
- To provide a structured digital system for restaurants
